# COSHIAN Licenses

このリポジトリは、COSHIAN Develop License（CDL）と COSHIAN Music License（CML）を独立して管理します。

- [CDL v1.0](CDL/README.md) は指定された開発関連作品を対象とする現在の正式版で、2026年11月25日に公開されました。
- [CML](CML/README.md) は音楽および音楽関連作品向けに開発中で、条件は未確定です。

## CDL v1.0 の適用

十分な権利を持つプロジェクト所有者は、対象となる作品に CDL v1.0 を明示的に適用できます。正文を確認し、作品にライセンス名とバージョンを明記してください。日本語のライセンス本文全体をプロジェクトのルートにある `LICENSE` ファイルに含めることを推奨します。表示例は次のとおりです。

```text
This project is licensed under the COSHIAN Develop License v1.0 (CDL).

SPDX-License-Identifier: LicenseRef-CDL-1.0

Official Attribution: COSHIAN

Copyright © 2026 COSHIAN Studio.
```

著作権表示は実際の権利者を反映してください。上記のクレジット表示例は、指定されている場合に適用されます。`LicenseRef-CDL-1.0` はカスタム SPDX LicenseRef であり、SPDX に公式登録されたライセンス識別子ではありません。CDL は OSI の承認を受けておらず、独立した法的審査は完了していません。他のライセンスとの互換性も正式には確認されていません。

`main` は承認・公開済みバージョン用、`develop` は草案、翻訳、文書、改定提案用です。バージョンは独立して管理します。公開済みの正文はその場で変更せず、実質的な変更は新しいバージョンで公開します。将来のタグには `CDL-v1.1` や `CML-v1.0`、草案には `CDL-v1.1-draft` や `CML-v0.3-draft` などを使用できます。提案中の `LicenseRef-CML-1.0` は将来の使用に備えたもので、CML v1.0 の存在や SPDX 登録を意味しません。

質問や提案については [CONTRIBUTING.md](CONTRIBUTING.md)、詳細は [CDL FAQ](CDL/FAQ.md) と[リポジトリのライセンス通知](LICENSE)を参照してください。
