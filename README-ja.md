# COSHIAN Licenses

このリポジトリは、COSHIAN Develop License（CDL）と COSHIAN Music License（CML）を独立したライセンスとして一元管理します。

- [CDL](CDL/README.md) は開発作品向けに構想されています。[v1.0 日本語本文](CDL/versions/1.0/LICENSE-ja.md)と非公式の英語参考訳を確認できます。承認・公開状況は未確認です。
- [CML](CML/README.md) は音楽および音楽関連作品向けに構想され、開発中です。条件は未確定です。

承認済みまたは公開済みと確認されたバージョンはありません。`main` は承認・公開済みバージョン用、`develop` は草案、翻訳、文書、改定提案用です。[CDL のバージョン情報](CDL/README.md)と [CML のバージョン](CML/versions/README.md)を参照してください。

ライセンスの日本語本文を正文とします。英訳はリポジトリ所有者が明示的に承認しない限り非公式の参考訳です。CDL v1.0 の第12.6項では、正式な日本語本文と非公式の翻訳に相違がある場合、適用法に反しない範囲で日本語本文を基準としています。

ライセンスを適用するには、所有者が承認・公開した特定のバージョンを選び、その正文を確認して、作品にライセンス名とバージョンを明示してください。現時点でこのリポジトリから適用できるバージョンはありません。

質問、修正、改定の提案は [CONTRIBUTING.md](CONTRIBUTING.md) の手順に従ってください。提案には所有者による確認と承認が必要です。

将来のタグ名には `CDL-v1.0`、`CDL-v1.1`、`CML-v1.0`、`CML-v1.1` を使用できます。草案には `CDL-v1.1-draft` や `CML-v0.3-draft` などを使用できます。バージョンは独立して管理します。公開済みの正文はその場で変更せず、実質的な変更は新しいバージョンで公開します。

`LicenseRef-CDL-1.0` と `LicenseRef-CML-1.0` は提案中のカスタム SPDX LicenseRef 識別子であり、SPDX に公式登録されたライセンス識別子ではありません。CML の識別子は将来の使用に備えたもので、CML v1.0 の存在を意味しません。
