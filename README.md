# COSHIAN Licenses

This repository manages the COSHIAN Develop License (CDL) and COSHIAN Music License (CML) independently.

- [CDL v1.0](CDL/README.md) is the current official release for designated development-related works, published on November 25, 2026.
- [CML](CML/README.md) is under development for music and music-related works; its terms are not finalized.

## Applying CDL v1.0

A project owner with sufficient rights can explicitly apply CDL v1.0 to eligible works. Review the authoritative text and identify the license and version with the work. We recommend including the complete Japanese license text in the project's root `LICENSE` file. An example notice is:

```text
This project is licensed under the COSHIAN Develop License v1.0 (CDL).

SPDX-License-Identifier: LicenseRef-CDL-1.0

Official Attribution: COSHIAN

Copyright © 2026 COSHIAN Studio.
```

Copyright notices must identify the actual rights holder. The attribution example applies where designated. `LicenseRef-CDL-1.0` is a custom SPDX LicenseRef, not an officially registered SPDX license identifier. CDL is not OSI-approved, independent legal review has not been completed, and compatibility with other licenses has not been formally established.

`main` is intended for approved, published versions; `develop` is for drafts, translations, documentation, and proposed amendments. Versions are managed independently. Published authoritative texts are not modified in place; substantive changes require a new version. Future tags may use names such as `CDL-v1.1` or `CML-v1.0`, and drafts may use `CDL-v1.1-draft` or `CML-v0.3-draft`. The proposed `LicenseRef-CML-1.0` is reserved for possible future use and does not mean CML v1.0 exists or is registered with SPDX.
