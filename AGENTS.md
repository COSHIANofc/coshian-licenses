# Instructions for agents

- Treat authoritative Japanese license texts as legal source documents.
- Never silently rewrite published license terms or modify published versions in place.
- Never introduce new legal conditions without explicit owner approval.
- Keep CDL and CML independent.
- Preserve article numbering and internal references.
- Keep translations consistent with the Japanese original; identify unofficial translations.
- Never fabricate legal review results, OSI approvals, or SPDX registration.
- Never push, merge, create remote tags, or publish releases without explicit authorization.
- Preserve user changes and avoid destructive Git commands.
- Keep the repository simple and maintainable.
- Report ambiguity instead of making unauthorized legal decisions.
